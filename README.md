# bytemd-plugin

A plugin collection for [bytemd](https://github.com/pd4d10/bytemd)

> [!NOTE]
> I really enjoy using bytemd as a Markdown rendering library. However, since bytemd and its plugins haven't been updated in a while—and upstream dependencies are now far behind—the project seems unmaintained (plus, HashMD v2 appears to be stalled). Because of this, I’ve stepped in to make a few updates and improvements where I can.
